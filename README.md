# BYME.AM — Android приложение

Приложение-оболочка сайта BYME.AM (WebView, Kotlin). Всё, что есть на сайте, работает в приложении; обновления сайта
сразу видны в приложении без новой сборки.

Что добавляет приложение поверх сайта:
- **Поиск по фото** — камера или галерея прямо из окна поиска (выбор файлов на сайте тоже работает: документы, оплата, чат).
- **Голосовой поиск** — через распознавание речи Android (в WebView нет Web Speech API, приложение его подставляет).
- **Геолокация** — «моё местоположение» в доставке.
- **Скачивание** счетов / PDF / выгрузок, в т.ч. созданных в браузере (blob:) → папка «Загрузки».
- Телефон, WhatsApp, Telegram, Viber, карты, e-mail открываются в своих приложениях; оплата банком — внутри приложения.
- Экран «Нет соединения» с кнопкой «Повторить», обновление страницы жестом вниз, кнопка «Назад» — по истории страниц.
- Окно «Скачать приложение» на сайте внутри приложения скрывается (User-Agent содержит `BYMEApp/<версия>`).

## Сборка (GitHub Actions)
Actions → **Build APK** → Run workflow. Параметры: адрес сайта (`http://91.98.119.91` по умолчанию) и applicationId
(`am.snp.shop` — как в админке → «Приложение»). Готовый APK — во вкладке **Releases** (и в Artifacts запуска).
Каждый push в `main` тоже собирает APK. Номер версии = номер запуска (versionCode растёт сам).

### Подпись
Секреты репозитория (Settings → Secrets and variables → Actions):
`BYME_KEYSTORE_BASE64`, `BYME_KEYSTORE_PASSWORD`, `BYME_KEY_ALIAS`, `BYME_KEY_PASSWORD`.
Ключ должен быть всегда один и тот же — иначе новая версия не установится поверх старой. Храните файл ключа и пароль в надёжном месте.

## Важно
- Адрес `http://…` (IP) — в приложении разрешён незашифрованный трафик. После перехода на домен с HTTPS соберите с `https://домен` —
  незашифрованный трафик отключится автоматически.
- Вход через Google внутри WebView Google блокирует (политика Google) — вход по email/паролю работает.
- Локальная сборка: Android Studio → Open → эта папка (нужны JDK 17 и Android SDK 35), или `gradle :app:assembleRelease`.
